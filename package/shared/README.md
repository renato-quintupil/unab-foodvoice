# package/shared

**Librerías compartidas** del monorepo FoodVoice.

- **Contenido:** tipos de dominio (Pedido, Producto, HistorialEstado, Ubicacion…), utilidades y contratos comunes reutilizados por `apps/*` y `services/*`
- **Objetivo:** una única fuente de verdad para los modelos de datos compartidos
- **Agente responsable:** `shared-libs`
