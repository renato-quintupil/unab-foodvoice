# Proyecto FoodVoice

FoodVoice es una plataforma digital de delivery de alimentos en la que participan tres actores principales —cliente, local comercial y repartidor— y cuyo propósito es facilitar la compra, preparación y entrega de productos alimenticios mediante tecnologías digitales.

- **Objetivo general:** Diseñar una propuesta de solución informática para FoodVoice que mejore la gestión de pedidos
